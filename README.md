# Ефір-ШІ / SITREP-AI — прототип

Веб-застосунок (PWA): слухає звук із мікрофона або лінійного входу, ділить його на повідомлення, розпізнає мову на самому пристрої (Whisper у браузері), класифікує за словником тригерів і веде стрічку подій із зведенням та SITREP.

- Розпізнавання й дані — лише на пристрої (IndexedDB). Мережа потрібна один раз, щоб завантажити модель.
- Тест без радіостанції: ☰ → «Демо-запис», «Аудіофайл…» або введення тексту.
- Це прототип для перевірки ідеї, не бойовий засіб: без шифрування бази, без діаризації, без LLM.

Файли: `index.html`, `app.js` (звук, стрічка, SITREP), `rules.js` (словник і класифікація), `asr-worker.js` (розпізнавання), `sw.js` (офлайн-кеш).
